# Nexus Platform 🚀

A modern investor & entrepreneur collaboration platform built with React, TypeScript, and Tailwind CSS.

## ✨ Week 1 Features
- Consistent UI theme with design tokens
- Meeting scheduling calendar (FullCalendar)
- Add / modify availability slots
- Send / accept / decline meeting requests
- Confirmed meetings displayed on dashboard

## 🛠️ Tech Stack
- React 18 + TypeScript
- Vite
- Tailwind CSS
- React Router v6
- FullCalendar
- Lucide React Icons

## 🚀 Getting Started

# Install dependencies
npm install

# Start development server
npm run dev
```
